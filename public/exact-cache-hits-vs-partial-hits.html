Exact cache hits vs partial hits: what the difference actually means.

Not all savings signals mean the same thing. AI Optimizer separates exact local cache hits from partial provider-side reuse so you can understand what actually happened.

Quick answer

An exact cache hit means the repeated request was fully served from the local cache. A partial hit means there was some provider-reported reuse, but not a full local cache resolution. Treating them as the same thing makes optimization harder to judge.

Exact cache hits

This is the cleanest signal. The work was repeated and AI Optimizer handled it locally instead of paying for the same upstream call again.

Partial hits

This is a narrower signal. Some reuse happened, but it was not the same as a full local exact-hit outcome.
